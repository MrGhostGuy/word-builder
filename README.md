# Word Builder

A high-end Scrabble-style word game built for the Rabbit R1. Full 15x15 board with premium squares, the real 100-tile bag, blank tiles, +50 bingos, and validation against the full TWL tournament lexicon (178,691 words). Play against four AI opponents: PIP-7 (Rookie), VOLT (Challenger), LEXA (Wordsmith), and OMEGA-9 (Grandmaster). Neon RGB futuristic design with animated tile placement, sized for the R1 portrait screen.

Open `index.html` in any browser to play, or install it on a Rabbit R1 as a creation.
